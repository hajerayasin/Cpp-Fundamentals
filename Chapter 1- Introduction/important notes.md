# Important Notes — Chapter 1

## Types of Errors

### Syntax Error

Errors caused by breaking programming rules.

Example:

```cpp
cout << "Hello"
```

Missing semicolon.

---

### Logical Error

Program runs but gives wrong output.

---

### Runtime Error

Errors occurring during execution.

---

# Compiler

A compiler converts C++ code into machine language.

Examples:

- GCC
- Dev C++
- Turbo C++
