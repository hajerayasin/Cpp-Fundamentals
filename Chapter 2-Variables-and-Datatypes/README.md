# Variables

Variables are memory locations used to store data.

Example:

```cpp
int age = 18;
```

Here, `age` is a variable.

---

# Data Types

Data types define the type of data stored in a variable.

| Data Type | Description |
|-----------|-------------|
| int | Stores integers |
| float | Stores decimal numbers |
| double | Stores large decimal numbers |
| char | Stores single character |
| string | Stores text, collection of characters|

---

# Variable Declaration

Declaration tells the compiler about the variable.

```cpp
int marks;
```

---

# Variable Initialization

Initialization means assigning value to a variable.

```cpp
int marks = 90;
```

---

# Constants

Constants are fixed values that cannot be changed.

```cpp
const float PI = 3.14;
```

---

| Operator | Meaning |
